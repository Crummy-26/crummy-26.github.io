### Observations worth keeping

- input() always returns as a string
- when converting float() to int(), 
	- if `x < 0`, python **rounds up** int(x)
	- if `x > 0`, python **rounds down** int(x)
		- NOT THE CLOSEST INTEGER
- When initializing variables, you can use:
	`var = None`
	- The None value has no value and wont be a bug in the code
- `random.randint(a,b)`
	- the `randint` range is **inclusive**, so `(0,11)` will include 0 and 11
