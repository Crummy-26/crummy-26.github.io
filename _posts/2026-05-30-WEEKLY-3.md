- ## What did I learn?
- Fibonacchi's rabbits follow a rather set pattern:
	- *Babies this month = adults from last month × k*
	- *Adults this month = adults from last month + babies from last month*
	- *Total = babies + adults*
	  ![](/assets/img/posts/FibonacchiRabbits.png)
	  ---
- Total rabbits of this month = Sum of rabbits of previous two months
	- `f(n) = f(n-1) + k * f(n-2)` ==> Recurrence relation Arithmetic sequence
- If you need to edit/ obtain the last values of an array, use the negative index
  
  ```python
  array = [1, 2, 4]
  
  last_value = array[-1]
  second_last_value = array[-2]
  ```
- In an array of strings with unicode characters, you can use the following to strip the unicode and give the clean string:
  
  ```python
  lines = ["hello\n", "\tbanana"]
  clean_line = [x.strip() for x in lines]
  ```
- Instead of  the alternative for loop:
  
  ```python
  lines = ["hello\n", "\tbanana"]
  clean_lines = []
  for i in lines:
	  cleaned = lines.strip(i)
	  clean_lines.append(cleaned)
  ```

- ### File handling revision
- Python file handling is done through 5 modes:
   1. `"r"` = Read
   2. `"w"` = Write if exists; Create and write if it doesn't exist
   3. `"a"` = Add to a file. Crashes if it doesn't exist
   4. `"x"` = Create a file. Crashes if it exists.

- `enumerate()` can be used for easily indexing items of a list
  For example,
  ```python
  students = [["Alice", 85, 92], ["Bob", 90, 88]]
  
  for n, (name, score1, score2) in enumerate(students, start=1):
    print(f"{n}: {name} {score1} {score2}")
  ```
  
  Note how `n` is a different item from the variables `name`,  `score1` and `score2`.
  `n` is the index/line number used by `enumerate` to number each item within `students[]`
  This is then used to print *line numbers* when printing the output in an f-string

- ## How this connects to Bio/Chem
	- File handling is crucial for Biostatistics due to the sheer scale of genomic data present in the real world that we have to deal with. So it'll be a crucial skillset for me to nurture every time I code.
	- The Fibonacci pattern and recurrence sequence helps predict growth in systems, populations, living beings themselves, etc. Being able to compute it will help bring light to large numbers and solutions through such simple sequencing.
		- According to claude, this is referred to as **Dynamic programming** and is essential in real world cases alike:
			- **Sequence alignment** (comparing two DNA sequences to find similarities) — the Smith-Waterman and Needleman-Wunsch algorithms both use dynamic programming. Instead of rabbits, you're filling a matrix where each cell's value depends on the cells before it
			- **RNA secondary structure prediction** — folding algorithms use recurrence relations to find the minimum energy structure
			- **Hidden Markov Models** — used in gene finding and protein structure prediction, built entirely on the same "use smaller solved cases to build larger ones" logic.
